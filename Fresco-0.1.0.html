Fresco 0.1.0

Fresco 0.1.0 — the first release.

A menu-bar app that rotates your desktop wallpaper, from nine sources:
Unsplash, Pexels, Wallhaven, Wikimedia Commons, DeviantArt, Flickr,
Reddit, Bing's daily image, and any folder on your Mac.

- Rotate on a schedule, or grab the next one from the menu whenever
- One wallpaper across every display, or a different one per display
- Bias picks light or dark to match your system appearance
- Photographer attribution that links back to the original
- Listings are cached, so browsing spends far fewer API requests
- Several sources work with no API key at all; the rest take one in Settings

This is the first build delivered through Sparkle — the one that teaches
Fresco to update itself. From here, new versions arrive in the menu bar.
